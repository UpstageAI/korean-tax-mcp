# 판정 검토 보고서 — 출력 형식 안내

> 이 파일은 `run_judgment.py`가 Solar Pro 4로 생성하는 보고서의 목차·형식 기준입니다. 보고서를 읽는 사람과 프롬프트를 관리하는 사람이 참고합니다. (실제 형식 강제는 run_judgment.py 안의 시스템 프롬프트가 담당)

---

## 보고서 목차 (생성 결과물의 구조)

```
# 비거주자·거주자 판정 검토 보고서

(맨 위) 가상/합성 사례 여부 및 검토 보조 자료임을 알리는 안내문 1개
        — 본문에서는 "가상" 표기를 반복하지 않는다

## 1. 사례 개요
   누가 / 어떤 소득·기간 / 무엇이 쟁점인지 요약

## 2. 적용 규칙 요약
   조문 번호를 명시한 근거 요약 (소득세법 §1의2, 시행령 §2·§3·§4)

## 3. 단계별 검토
   3-1. 1단계 — 소득세법상 거주자 (주소 판정 / 183일 거소 판정)
   3-2. 2단계 — 이중거주자 (증명책임 명시)
   3-3. 3단계 — 조세조약 Tie-break (적용되는 경우만)

## 4. 쟁점 및 불확실 요소
   "확인 필요"로 입력된 항목, 결론을 흔들 수 있는 변수

## 5. 참고 판례 (적용 취지)
   가상 사례에 그대로 적용된다고 쓰지 않고, 취지 참조로만 표기

## 6. 종합 검토의견 (Summary)
   정도 표현으로 결론: "거주자 가능성 높음" / "비거주자로 볼 여지 있으나 확인 필요" / "단정 불가"

## 7. 디스클레이머
   합성 데이터 여부, 현행 법령·확정 판례 확인 필요, 전문가 상담 필요
```

## 읽는 사람을 위한 포인트

- **6번(Summary)부터 읽어도 된다.** 결론 방향과 조건이 거기 요약돼 있다.
- 3번 단계별 검토는 "왜 그 결론인지"의 근거 사슬이다. 조문 번호가 붙어 있으니 검증할 때 해당 조문만 대조하면 된다.
- 4번 쟁점은 "이 값이 바뀌면 결론이 바뀔 수 있다"는 목록이다. 실무에서는 이 항목들을 공식 자료(출입국기록 등)로 먼저 확정해야 한다.
- 보고서의 결론은 항상 정도 표현이다. "확정 판정"이 나오면 오히려 프롬프트 위반이므로 재실행하거나 결과를 신뢰하지 말 것.

## 결론 문구 예시 (세 가지 패턴)

- 거주자 방향: "…을 종합하면 국내 거주자로 판정될 가능성이 높다. 다만 …에 따라 결론이 달라질 수 있으므로 단정할 수 없으며, 조세 전문가 검토가 필요하다."
- 비거주자 방향: "…을 종합하면 비거주자로 판정될 가능성이 높다. 다만 …의 확인이 필요하여 단정할 수 없다."
- 불명확: "현재 자료만으로는 …이 확정되지 않아 결론을 내리기 어렵다. …자료 확보 후 재검토가 필요하다."
