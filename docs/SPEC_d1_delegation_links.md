# SPEC d1 — 조문 따라가기(위임 연결) 길 트기 (2026-10-12)

## 배경 (세무사 기출 17회차 실측)
- 법 조문에 "대통령령으로 정하는"이 보인 뒤 Solar가 시행령을 연 비율 41~50%, 정답 시행령 조문을 정확히 연 비율 약 40%
- law_article 결과에 행선지(시행령 몇 조)가 없어 조 번호를 짐작해야 함. with_delegation은 시행령 입력에서 KeyError('법령')

## 구현
1. `law.links(law_name, article, as_of="")` → {"상위": [...], "하위": [...]} — 각 항목 {"법령", "조"} (+ 있으면 "항", "구절", "출처")
   - 출처 ①: 법제처 3단비교 공식표(_three_tier). 법률·시행령·시행규칙 어느 쪽 입력이든 양방향 조회(시행령 입력이면 계열 법률의 표에서 시행령조문이 이 조인 행 → 상위 법률 조, 같은 행의 시행규칙 조 → 하위)
   - 출처 ②: 하위 법령 전문(조문 전체 1회 조회 후 캐시)에서 `법 제N조(제M항)(제K호)…에서 "…으로 정하는 X"란`(시행규칙은 `영 제N조…`) 구절 정의를 찾아 상위 조문의 그 구절과 짝 — 이때 "구절"·"항"을 채움
   - ①∪② 합집합, (법령, 조) 중복 제거(구절 정보는 보존)
   - 법령명 비교는 공백만 무시, 급(시행령·시행규칙)은 유지
2. `law_article` 기본 출력에 "연결" 필드 추가: links 결과(포인터만, 본문 없음). 실패해도 본문 조회는 그대로 반환(연결만 빈 값 + 사유)
3. `with_delegation=True`가 시행령·시행규칙 입력에서도 동작(입력 조를 기준으로 상위·하위 단계를 모아 위임체계 반환)
4. 도구 설명(description)에 "결과의 '연결'에 상위·하위 조문 위치가 있으니 그 조를 law_article로 이어서 조회" 한 줄 추가
